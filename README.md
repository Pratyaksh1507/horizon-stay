# Horizon Stay

### Executive Resort Management Dashboard

A modern resort management dashboard designed for managing
bookings, cabins, guests, check-ins, check-outs and business analytics.

## ✨ Highlights

- Resort booking management
- Cabin CRUD operations
- Guest management
- Check-in / check-out workflows
- Revenue & booking analytics
- Interactive geographic visualization
- Dark / light theme
- Responsive dashboard
- Server-state management with React Query
- Supabase backend integration

## 🛠️ Tech Stack

React · Vite · JavaScript · Tailwind CSS · Supabase
React Query · Recharts · Framer Motion · React Router
